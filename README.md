# Age Guesser

質問に答えると、年齢を当ててくれるWebゲームです。アキネーターとかのパロディで、中身はただの二分探索です。

## 遊び方

1. 0〜120の数字を思い浮かべます。ここでは年齢とします。
2. 表示された年齢に対して「もっと下」「正解！」「もっと上」で回答します。
3. 回答に応じて候補を絞り、年齢を当てます。

## 使用技術

- HTML
- CSS
- JavaScript

## 実行方法

index.htmlをブラウザで開くと遊べます。
