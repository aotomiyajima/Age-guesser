# Age Guesser

質問に答えると、年齢を当ててくれるWebゲームです。アキネーターとかのパロディで、中身はただの二分探索です。

## 遊び方

1. 0〜120の数字を思い浮かべます。ここでは年齢とします。
2. 「ゲームを始める」を押します。
3. 表示された年齢に対して「もっと下」「正解」「もっと上」で回答します。
4. 回答に応じて候補を絞り、年齢を当てます。

グレーの初期アイコン風キャラクターは、1〜3ターン目は頭を傾けて「？」、4〜6ターン目は電球、7ターン目は「！」を表示します。開始前と終了後は通常の姿に戻ります。
